# Topoliner для RustGIS

Расширение-процесс RustGIS для топологии полигональных и линейных
покрытий без QGIS. Инструменты находят нарушения и отделяют мусор
от возможного смысла. Расчёты повторяют модуль QGIS Topoliner и сверяются
с его прогонами.

Лицензия GPL 3 или новее, как у модуля.

## Инструменты

Все одиннадцать инструментов модуля.

| № | Название | Имя |
|---|---|---|
| 1.01 | Проверка топологии полигонов | `topologyaudit` |
| 1.02 | Проверка топологии линий | `lineaudit` |
| 1.03 | Очистка топологии полигонов | `topologyfix` |
| 1.04 | Очистка топологии линий | `linefix` |
| 1.05 | Сшивка узлов и вершин | `topologyclean` |
| 1.06 | Вставка недостающих узлов | `insertnodes` |
| 1.07 | Контроль сборки по атрибуту | `assemblycheck` |
| 1.08 | Ввод контуров в покрытие | `cutintocoverage` |
| 2.01 | Топологическое упрощение | `topologysimplify` |
| 2.02 | Границы полигонов линиями | `boundaries` |
| 2.03 | Топологическая модель покрытия | `coverage` |

Каждый сверен со всеми своими прогонами модуля на двух языках.
Ограничения и открытые просьбы к крейту - в заметке
`topoliner-rustgis_status.md` общей папки заметок.

## Устройство

Связь с RustGIS, окно инструмента по `tools.json`, перевод градусов
в метры зоны UTM, итоги слоями и упаковку даёт крейт `rustgis-kit`,
тег v0.1.6. Своё у продукта:

| Модуль | Что в нём |
|---|---|
| `product` | трейт `Product`: каталог, настройки, расчёт, команда «О программе» |
| `audit` | 1.01: находки, сводка, строки журнала |
| `line_checks` | 1.02 и 1.04: нарушения линий и их очистка |
| `topo_fix` | 1.03: конвейер очистки полигонов |
| `assembly` | 1.07: сборка группы в одно тело |
| `cut` | 1.08: ввод контура в покрытие, три режима |
| `simplify` | 2.01: прореживание дуг и сглаживание |
| `clean` | 1.05 и 1.06: сшивка, вставка узлов, сборка слоя |
| `boundaries` | 2.02: границы покрытия отдельными линиями |
| `coverage` | 2.03: узлы, дуги и кольца как списки дуг |
| `rings` | геометрия кольца: площадь, ширина, повторы вершин, иглы, самокасания |
| `snap` | вставка узлов, вершина на ребре соседа без узла |
| `arcs` | разбор покрытия на дуги между узлами ветвления |
| `backend` | булевы операции, корректность, внутренняя точка |
| `rounding` | округление величин до значащих цифр |
| `values` | значения прогона модуля в объекты проверки |
| `manifest` | раздел `tools` манифеста `plugin.json` |

Геометрия идёт через крейт `geo`, у модуля на этом месте GEOS. Операции
`geo` считаются по сетке, шаг которой зависит от охвата, поэтому итог
булевой операции округляется до разряда крупнее шага сетки. Без этого
ровная координата входа возвращается со следом перевода в целые.

## Данные модуля

| Файл | Откуда |
|---|---|
| `tools.json` | `tools/export_tools.py` модуля, схема `toolspec.py` |
| `fixtures/tool_runs.json` | прогоны алгоритмов Processing без окна |

Оба файла копируются из рабочей копии модуля `C:\Dev\topoliner`
и вручную не правятся. Прогон снят настоящим запуском алгоритма, поэтому
в него входит всё, что делает диалог поверх ядра. Это округление величин,
состав полей, порядок объектов и пояснения.

## Проверка

```
cargo test
cargo clippy --all-targets -- -D warnings
```

Раздел `tools` манифеста собирается из `tools.json`. Переписать его
в `plugin.json`:

```
TOPOLINER_MANIFEST=1 cargo test
```

## Сборка пакета

```
powershell -File scripts\package.ps1
```

В `dist` появятся папка `topoliner` для «Add Plugin Folder…» и пакет
`topoliner-<версия>.rgplugin` для установки из файла. Упаковку делает
сценарий крейта, он один на всю линейку.
